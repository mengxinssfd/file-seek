# file-seek

在命令行进行文件搜索

# 使用

先 `pnpm install` 安装依赖

# 在命令行中输入文件夹

命令行输入模板 `tsx src/seek.ts "文件夹绝对路径1,文件夹绝对路径2" 搜索目标 是否深度搜索(默认Y开启，输入任意为否)`
搜索到以后可以选择打开、在文件夹打开、勾选等3个选项

# 在json文件中读取文件夹

在**json**/seekByJ.json文件内添加目标文件夹
命令行输入模板 `tsx src/seekByJ.ts 查找目标 深度查找(默认Y开启，输入任意为否)`
搜索到以后可以选择打开、在文件夹打开、勾选等3个选项
在文件夹多且不需要更改的时候使用
